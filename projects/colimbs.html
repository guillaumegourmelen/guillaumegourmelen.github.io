Co-Limbs — Wearable Collaborative Robot Arms

Image coming soon

Co-Limbs (Collaborative Limbs) is a control interface for wearable supernumerary robotic arms, built around a single core principle: no dedicated hand controller. Because servo-driven wearable arms are normally stiff and non-backdrivable, positioning them usually needs joysticks or limb tracking. Co-Limbs instead lets a first-time user move the arms by hand, immediately, with no training.

Each arm carries a 6-axis force sensor on a forearm handle. The measured wrench is transformed into world coordinates and converted to a target velocity through an assumed mass-damper dynamics (admittance control), then to joint velocities via inverse kinematics. This makes the otherwise rigid, servo-driven arms feel back-drivable: push or pull the handle, and the arm moves with you.

Three modes were demonstrated: Passive Assist (the user positions the arm by hand for a task, e.g. holding an umbrella), Power Assist (the arm shares a load with the user, e.g. lifting a box), and Playback (the arm replays a movement it was guided through, e.g. fanning). Demonstrated live at ACM SIGGRAPH Asia 2019 Emerging Technologies in Brisbane.

Key insight: Wearable extra arms don't need a dedicated controller if they're built to be physically collaborative. A force sensor and admittance control let the user guide the arm the way they'd guide a held tool — turning a third arm from something to consciously operate into something to simply move.
